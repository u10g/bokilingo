## 問題文の構造

本試験問題集の第1問（読み取れた58問）の問題文から、情報が並ぶ順番と表記を調べた。アプリの問題文はこの形にそろえる。

アプリの問題文と空欄は、次の4つの原則で作る。

| 原則 | 内容 |
|---|---|
| 順番 | 問題文の中で情報が出る順番を、本試験とそろえる |
| 情報量 | 本試験の情報量はそのまま持ち込まない。通しで解く流れはストーリーで扱い、レッスンは同じ順番の問題文を縮めて（取引は空欄の日付まで）、空欄を1〜2マスにする。売上総利益（売上高 → 売上原価 → 売上総利益）のように1本の計算になっているものだけは3マスまでにする |
| 入力順 | 空欄は、数字が判明する順に入力させる（下表） |
| 著作権 | 問題文はすべてオリジナルで作る。本試験の問題文は写さない |

| 表 | 入力順 | 実装 |
|---|---|---|
| 精算表（一部） | 修正記入 → 整理後（整理後は修正記入から計算するため） | `ws()` |
| 商品有高帳 | 受入・払出は数量 → 単価 → 金額。移動平均法で仕入れた後・返品の後の残高は数量 → 金額 → 単価 | `il()`・`ilSummary()` |
| 勘定記入 | 日付順。同じ日は前期繰越を最初に置き、損益への振替、締切り（次期繰越など）、合計は最後に置く | `la()` |

以下は、第1問から順に、本試験で使われている書き方である。

```text
［時点］、［前提］［相手先］［対象（属性）¥金額］を［行為］し、［決済］。なお、［補足条件］。
例：期首に、備品（取得原価¥…、減価償却累計額¥…、間接法で記帳）を¥…で売却し、代金は月末に受け取ることとした。
```

| 要素 | 本試験での書き方 | 出現数（58問中） |
|---|---|---|
| 金額 | `¥200,000`（単価は `@¥1,200`） | 55 |
| 時点 | 文頭に置く（本日・期首・決算日において・月末に） | 本日9、決算7、期首6 |
| 前提 | 行為の前に置く（さきに〜していた・前期に〜していたので、本日〜） | 6 |
| 相手先 | 得意先・仕入先・従業員などを主語や目的語として書く | 得意先9、従業員9、仕入先3 |
| 属性 | 対象の直後のかっこにまとめる（取得原価・累計額・記帳方法、数量と単価、利率と期間） | 9 |
| 決済 | 「代金は〜」「残額は〜」で行為の後に置く。後払いは「〜こととした」（「ことにした」は0） | 残額17、代金は10、こととした10 |
| 補足条件 | 文末に「なお、〜」で置く（記帳方式・引当金の残高・3伝票制・すぐに使用した など） | 16 |
| 訂正仕訳 | 誤りを文章で書く（誤って売上として処理していた）。仕訳そのものは示さない | — |
| 解答のヒント | 書かない（相手科目や「取得原価に含める」などの処理方法） | — |

減価償却（第3問の決算整理事項、4問）は、対象と方法を1文で示し、資産ごとの条件を1行ずつ並べ、期中取得の扱いを「なお、」で添える。取得原価は残高試算表にあるので書かない。資産が1つなら「残存価額をゼロ、耐用年数を6年とする定額法により」と1文にする。

```text
建物および備品について、定額法により減価償却を行う。
建物：残存価額ゼロ　耐用年数30年
備品：残存価額ゼロ　耐用年数6年
なお、備品のうち10月1日に取得した¥120,000については、同様の条件で月割により計算する。
```

第1問の固定資産の売却は「期首に、不要になった備品（取得原価¥…、減価償却累計額¥…、間接法で記帳）を¥…で売却し、」と、時点を文頭に置く。

第2問の勘定記入（第145回・第147回の改題、サンプル問題）は「当社（決算年1回 3月31日）における次の取引（および決算整理事項）にもとづいて、○○勘定に必要な記入を行い、締め切りなさい」と始まり、日付・摘要・金額を取引日順に記入するよう指示する。取引は「4月1日 …」と日付ごとに1行で示す。

- 前期末の経過勘定や期首残高は、取引ではなく前提（「なお、前期末に…振り替えている」）として示す。期首の再振替（開始記入）は受験者が自分で行う
- 決算整理は「3月31日 決算日を迎え、…のうち前払分を月割で計上した」のように、決算日の取引として書く
- 損益勘定への振替は「締め切る」に含まれ、取引としては書かない
- 勘定に関係しそうで関係しない取引が混ざる（例：土地購入時の仲介手数料は支払手数料にならない）

アプリでは、次の書き方にしている。

| 形式 | 問題文の書き出し | 空欄 |
|---|---|---|
| ストーリー | 「当社（決算年1回 3月31日）における次の取引にもとづいて、○○勘定に必要な記入を行い、締め切る。…」→ 前提（なお、…）→ 「4月1日 …」を1ステップに1つ | 取引ごとに摘要と金額。勘定に関係しない取引は空欄なし。最後に締切りの金額と合計 |
| レッスン（期中・決算整理） | 「…次の取引にもとづいて、○○勘定に記入する。」→ 取引1〜2行 | 1〜2マス |
| レッスン（期首） | 「…次の資料にもとづいて、○○勘定に期首の記入を行う。」→ 前提（なお、前期末に…） | 1〜2マス |
| レッスン（締切り） | 「当社（決算年1回 3月31日）の○○勘定の記入は次のとおりである。決算において、この勘定を締め切る。」→ 記入済みの勘定 | 締切りの金額と合計 |

商品有高帳は「次の○商品に関する取引にもとづいて、移動平均法によって…」と、商品・資料・方法の順に書く。通しで記入する流れはストーリー（`src/content/stories/inventory.ts`、移動平均法と先入先出法の2本）で扱い、取引を1つ読むごとにその取引で増える行の空欄を埋め、最後に売上高・売上原価・売上総利益を求める。

返品は、記入する欄を問題文で指示する形にそろえる（日商の第142回・第151回の講評。下記）。アプリでは「なお、仕入戻しは払出欄に、売上戻りは受入欄に記入する。」と添え、取引は「7月7日 仕入戻し 10個（7月5日仕入分）」と元の取引を示す。

| 返品 | 記入する欄と単価 | 残高 |
|---|---|---|
| 仕入戻し | 払出欄に、仕入れたときの単価（売価ではない） | 移動平均法は平均単価を計算し直す。先入先出法はその単価の在庫から減らす |
| 売上戻り | 受入欄に、払い出したときの単価（原価。売価ではない） | 移動平均法は平均単価を計算し直す。先入先出法は戻す在庫の位置が決まらないため出題しない |
| 売上総利益 | 売上戻りは、売上高から売価で、売上原価から原価で差し引く。仕入戻しは売上原価に含めない | — |

- 第142回の講評：仕入戻しは「問題文の指示にしたがって払出欄に記入」し、単価は仕入れたときの単価で書く。払出欄の単価に売価を書く誤答が多かった（https://www.kentei.ne.jp/wp/wp-content/uploads/2016/04/142-03-kouhyou.pdf）
- 第151回の講評：売上戻り分の原価は売上原価から差し引く。払出欄・売上戻りの単価欄に売価を書く誤答が目立った（https://www.kentei.ne.jp/wp/wp-content/uploads/2019/04/151-03-kouhyou.pdf）
- 講評の本文はこの環境から直接取得できず、検索結果の抜粋で確認した。売上戻りを受入欄に書く点は講評の抜粋では確認できず、教科書の一般的な扱いによる

## 反映方針

- **本試験頻度順コース：** 第1問の出題数の多い論点から並べ、出題の少ない決算系の論点を後半（第2問・第3問対策）に置く。
- **TAC順コース：** 教科書の章順に並べる。問題がまだない章（01・07〜10・12）は、論点を追加したときに差し込む。
- **★の論点：** 論点マスタに追加済み（correction・slips・subledger・inventory-ledger・statements）。訂正仕訳・伝票は仕訳穴埋め、補助簿は複数選択、商品有高帳・財務諸表のしくみは表の穴埋めで出題する。
- **第3問：** 精算表（worksheet）と財務諸表の作成（fs-preparation）を論点に追加した。本試験の精算表は8列でスマホに収まらないため、決算整理事項1つごとに関係する行だけを表の穴埋めで出題する。上の「決算整理事項の出現回数」の10項目のうち、未処理取引・誤記の修正を除く9項目を扱う（未処理取引は仮払金の整理の問題に含めた）。
- **第2問の勘定記入：** 論点 ledger-entry として追加した（12回中11回、勘定の記入や空欄を問う小問がある）。レッスンはT勘定の形式（ledgerAccount）で、期首の記入・期中の取引・決算整理・締切りのどれか1場面について、摘要（前期繰越・次期繰越・損益・相手科目）か金額を1〜2マス埋める。経過勘定（保険料・未払利息・受取家賃）、減価償却累計額、売掛金、繰越利益剰余金、損益、仕入の8勘定を扱う。通しの記入はストーリー6本（保険料・減価償却累計額・売掛金・繰越利益剰余金・受取家賃・仕入）で行う。
- **減価償却・経過勘定・貸倒引当金：** 苦手な論点なので、アプリでは要素ごとの小項目に分けた（減価償却：①年額 ②月割 ③間接法の仕訳 ④帳簿価額と売却 ⑤期中売却、経過勘定：①4つの分類 ②勘定科目 ③月数と金額 ④決算整理仕訳 ⑤再振替、貸倒引当金：①設定額 ②差額補充法 ③決算整理仕訳 ④貸倒れの処理 ⑤償却債権取立益）。仕訳の前に、計算（年額・月数・金額）と判断（どの分類か・損か益か）を「計算・判断」レッスン（二択・選択穴埋め）で1つずつ練習する。本試験の集計では、従来どおり depreciation・accruals・bad-debts の1論点として数える（`src/content/topics.ts` の ANALYSIS_TOPICS）。
- **集計の限界：** 回数が少ないうちは、出題数が1〜2の論点の順位は入れ替わりうる。回数を追加したら `stats --write` で更新する。
