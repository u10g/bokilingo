# 論点表（topic map）

参考書の分析結果をまとめ、コースの並び順と問題作成の優先度を決める根拠にする。
問題文は転記していない。各設問は、論点を判断するのに必要な範囲で要約している。

- 出典：TAC 本試験問題集（以下「本試験問題集」）第1〜4回の問題ページ、TAC出版「簿記の教科書 日商3級」（以下「教科書」）の目次。抽出と集計には `tools/pdf` を使った
- 論点IDは `src/content/topics.ts` に対応する。★は旧コースに問題がなかった論点（現在は追加済み）
- 本試験問題集には公式サンプル問題・過去の本試験（第145回・第147回など）の改題が含まれる

## 反映方針

- **本試験頻度順コース：** 第1問の出題数の多い論点から並べ、出題の少ない決算系の論点を後半（第2問・第3問対策）に置く。
- **TAC順コース：** 教科書の章順に並べる。問題がまだない章（01・07〜10・12）は、論点を追加したときに差し込む。
- **★の論点：** 論点マスタに追加済み（correction・slips・subledger・inventory-ledger・statements）。訂正仕訳・伝票は仕訳穴埋め、補助簿は複数選択、商品有高帳・財務諸表のしくみは表の穴埋めで出題する。
- **第3問：** 精算表（worksheet）と財務諸表の作成（fs-preparation）を論点に追加した。本試験の精算表は8列でスマホに収まらないため、決算整理事項1つごとに関係する行だけを表の穴埋めで出題する。上の「決算整理事項の出現回数」の10項目のうち、未処理取引・誤記の修正を除く9項目を扱う（未処理取引は仮払金の整理の問題に含めた）。
- **第2問の勘定記入：** 論点 ledger-entry として追加した（4回中3回出題）。T勘定の形式（ledgerAccount）で、摘要（前期繰越・次期繰越・損益・相手科目）と金額・合計を語群から埋める。経過勘定（保険料・未払利息・受取家賃）、減価償却累計額、売掛金、繰越利益剰余金、損益、仕入の8勘定を扱う。
- **集計の限界：** 回数が少ないうちは、出題数が1〜2の論点の順位は入れ替わりうる。回数を追加したら `stats --write` で更新する。
